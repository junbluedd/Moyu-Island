# Moyu Island 摸鱼岛

**x岛三方pc端** — X岛（nmbxd.com）的 Windows 桌面客户端，由dsh大肥鱼自动编写，本人监督改了10轮bug，连这个都是dsh总结的（。

用 .NET 8 + WPF 写的原生客户端，界面比网页版更适合长时间刷岛：三栏布局、
累积式翻页、一键发串、饼干多身份管理。

[摸鱼岛下载](https://github.com/junbluedd/Moyu-Island/releases/tag/main "下载")


\---

## 快速开始

1. 运行 `Moyu Island.exe`（免安装，拷到哪儿都能跑）
2. 点左下角 **🍪 饼干** → 导入你的饼干

   * 用手机 X岛 App 里的饼干二维码截图，点「**从剪切板复制的二维码图片识别**」即可
   * 也可以直接粘贴 `userhash` 值
3. 左上选一个版块，中间点任意串开始阅读

> 不导入饼干也能正常浏览所有内容，只是不能发串和回复。

## 浏览

* **三栏布局**：左边版块、中间串列表、右边串内容。版块栏可以折叠成一条图标列，给正文腾地方。
* **版块导航**：62 个版块按分组归好，另有时间线。母板块默认折叠、记住展开状态。鼠标悬停版块可以**加星收藏**，收藏的会排到最前面。
* **串列表**：等高卡片、内嵌缩略图、两行摘要、回复数。滚到底自动加载下一页。
* **跳转串号**：左上输入帖号回车，直接打开那个串（官方搜索接口已经不可用，用这个替代）。
* **串详情**：主串置顶 + 全部楼层平铺显示。

  * **累积式翻页**：向下滚自动加载下一页，向上滚自动加载上一页，**回看时已读过的内容不会消失**
  * **按页跳转**：工具栏显示「第 \[ ] 页 共 1/23 页 跳转」，输入页码回车，直接定位到那一页的第一条回复
  * **阅读进度**：自动记住每串看到第几页，下次打开直接回到那里
  * **只看 Po**：只看串主自己的回复
* **引用**：正文里的 `>>No.123` 可以直接点击，弹出被引用的原文；点引用里的串号能跳到那个串。
* **防剧透**：`\\\[h]这样\\\[/h]` 的内容默认显示为黑条，鼠标移到该楼层就能看到。
* **网址自动识别**：正文里的 `www.baidu.com` 这类裸网址会变成可点击链接。

## 发串与回复

* 表单顺序按使用频率排：**正文 → 图片 → 饼干 → 标题**
* **引用自动带上**，不用手动填帖号
* **水印默认关闭**（想要可以打开）
* **图片**：支持 jpg / png / gif / webp，也可以**截图后直接 Ctrl+V 粘贴**

  * 会自动按文件真实格式处理，WebP 会转成 PNG 再上传，避免发出打不开的图
  * 图片超过 5 MB 会提示
* **颜文字面板**：内置官方表情，五列网格排列；「呼伦悲尔」「鄂尔多厮」「举高高」这类特殊表情会按原样插入多行图案
* **roll 点**：一键插入骰子，服务端返回的点数会加大加粗显示
* **防剧透按钮**：选中文字后一键包上 `\\\[h]` 标签

## 饼干（多身份管理）

* **二维码识别导入**：直接识别饼干二维码图片，自动填好名字（可改）
* **多份保存**：可以存多份饼干随时切换，列表只显示备注名，不显示饼干内容
* **一键验证**：点「验证」会真的去问服务端这份饼干有没有被接受，结果直接标在列表上（✅/❌）
* **自动清洗**：粘贴的饼干会自动去掉换行等多余字符（这些字符会导致发帖失败）

## 图片查看

* 独立窗口，默认 1000×1000，可自由拖动缩放
* 打开就**适应窗口并居中**，超长截图、超宽全景、极小的图都能完整显示
* 滚轮缩放、按住拖动平移
* 快捷键：`0` 原始大小、`+`/`-` 缩放、`Ctrl+S` 保存到任意位置、`Esc` 关闭

## 收藏 / 历史 / 草稿 / 订阅

|功能|说明|
|-|-|
|订阅|服务端订阅，订阅过的串会出现在订阅列表里，按钮状态保持高亮|
|浏览历史|记录看过的串和**看到第几页**，点一下直接回去|
|草稿|没发出去的内容会存下来，可以继续编辑或删除|
|收藏版块|常用的版块加星，排在版块栏最前面|

## 外观与设置

* **主题**：深色 / 浅色 / 跟随系统，侧边栏 `◐ 主题` 一键切换
* **字号与行高**可调，长时间阅读更舒服
* **图片缓存上限**可调，避免占太多磁盘
* 所有操作反馈都在右下角短暂提示，不打断阅读

## 稳定性

* **域名自动跟随**：X岛主域会变（`nmbxd.com` → `nmbxd1.com`），启动时自动探测，不需要手动配置
* **主备切换**：主域名不通时自动换备用接口域名
* **不卡顿**：列表滚动、图片加载、复制操作都不会阻塞界面
* **出错有提示**：不会静默失败，异常会弹提示并记录到 `crash.log`

**系统要求**：Windows 10 1809 或更高版本（64 位）
